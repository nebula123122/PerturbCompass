# V28–V29 论文结果模块（截至 2026-10-27）

## 新增证据解决了什么问题

本轮首次在不同研究、同一 K562 疾病细胞、同一 CRISPRi 干预类型之间进行 held-out-target 验证，并把 control 细胞按外层折拆成完全互斥的训练组与测试组。因此，过去可能存在的“训练和测试共享 control 噪声”已被直接排除。

目标数据来自 Adamson et al. 2016 的 10X010 Perturb-seq 子屏。原始数据包含 65,337 个细胞；质控后保留 62,623 个细胞，其中 7,295 个为非靶向 control。表达矩阵按每细胞 10,000 总量归一化并 log1p，分析单位始终是扰动靶基因而不是单细胞。

## V28：冻结的跨研究验证

预先指定的主来源为 Replogle essential 屏，得到 57 个合格重叠靶点。程序级收缩相对 source-feature scalar Ridge 的 top-200 宏平均 MSE 改善 5.28%，靶点 bootstrap 95% CI 为 0.07%–9.50%，59.6% 靶点改善。未校正 sign-flip p=0.0287，但五项主比较 Holm 校正后 p=0.0861，因此严格主门槛未通过。

预设的 GWPS 来源敏感性分析包含 64 个靶点，改善 12.02%，95% CI 为 3.71%–19.02%，Holm 校正 p=0.0242。两套来源中，真实程序均显著优于 50 个保持程序大小不变的随机分组（精确 p=0.0196）。这说明基因程序携带真实的跨研究可迁移信息。

但是，gene-wise Ridge 和 low-rank Ridge 的 MSE 均低于直接程序收缩。主分析的排序为 low-rank 0.01344、gene-wise 0.01404、program 0.01512、scalar 0.01596、global 0.01615。由此不能宣称当前程序模型为最佳方法。

## V29：测量映射与程序残差的探索性分解

V28 之后提出以下操作性分解：

\[
\hat y = \underbrace{M_{\mathrm{low-rank}}(x)}_{\text{跨研究低秩映射}}
       + \underbrace{R_{\mathrm{program}}(x)}_{\text{程序结构残差}}.
\]

外层测试仍使用互斥 control。为避免在训练集残差上过拟合，低秩模型先在外层训练靶点内部进行四折 OOF 预测，程序模型只学习这些 OOF 残差；随后低秩模型在全部外层训练靶点重拟合，并与程序残差共同预测外层测试靶点。

essential 来源中，该分解相对 low-rank 再改善 0.89%，64.9% 靶点改善，95% CI 为 −1.21%–2.62%。GWPS 来源中改善 2.03%，59.4% 靶点改善，95% CI 为 −3.36%–5.79%。所有基因集合敏感性方向为正，两套来源均优于随机程序（p=0.0196），但 CI 跨 0，因此 V29 未晋级为确认性方法。

该结果支持“低秩映射之后仍可能存在小幅程序化残差”，但不能把低秩部分直接称为纯测量质量，也不能把残差直接称为纯生物学；这是统计上的操作性分解，仍需额外锚点或独立数据确认。

## 功效与下一数据规模

按逐靶点 paired loss difference 的事后估计，V29 的 Cohen dz 约为 0.11。采用单侧检验并以 0.0125 近似四项多重比较时，80% 功效约需：

- essential 效应估计：约 708 个独立靶点；
- GWPS 效应估计：约 858 个独立靶点。

由于开发集效应可能偏乐观，下一次确认应优先寻找至少 900 个可重叠基因扰动的独立 K562 CRISPRi 全转录组屏；若不存在，论文应把大规模同研究验证作为主开发证据，把 Adamson 作为方向一致但功效有限的跨研究证据。

## 当前最稳妥的论文表述

1. 程序结构在跨研究 K562 CRISPRi 转移中提供了超越标量校准、且超越随机程序的可重复信息。
2. 跨研究误差的主体更适合由 gene-wise/low-rank 映射吸收。
3. 在低秩映射后加入程序残差产生 1–2% 的方向一致增益，但当前外部屏功效不足，尚不能作为确认性主结果。
4. 论文创新候选应表述为“control-split、nested-cross-fitted 的低秩 nuisance mapping + program residual decomposition”，而不是声称已经识别了纯生物信号与纯测量质量。
