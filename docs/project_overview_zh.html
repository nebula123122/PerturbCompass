01 · The question

先把课题翻译成人话

什么叫“扰动”

把一个基因关掉或压低，然后测量细胞里成千上万个基因的表达怎样变化。每个被干预基因都会产生一条“反应指纹”。

什么叫“跨背景”

同一个基因在白血病细胞、肝癌细胞、T 细胞中未必产生同样反应。把 K562 的反应直接复制给 CD4 T 细胞，往往会错。

为什么需要 control

未扰动细胞像“当地天气”。它告诉我们目标背景本身的状态，但也混有测序深度、批次、细胞数等质量因素；所以 control 有用，却不能被简单当成纯生物真相。

anchor 是什么

在目标背景中真实测量的一小批扰动，相当于“当地路标”。模型用它们校准迁移规则，再预测剩余从未看过的扰动。

课题真正要解决的不是：“能不能把表达矩阵拟合得更像？”
而是：“在新背景里，哪一种迁移规则可相信；需要多少真实 anchor；改善是否在独立 guide、供者和功能外推上仍存在？”
02 · Evolution

三十多个版本，其实围绕三次转向

V1–V13
发现目标 control 有信号。曾观察到 target-control-only 改善 16.80%，高于完整组合的 12.69%。这说明目标背景不是没信息，而是早期 source-target 拼接方式可能把信号弄坏了。
V14–V21
从“直接加 control”转向“分离可迁移结构与测量质量”。引入桥接数据、互斥 control、分层与防泄漏，但也确认：仅靠一次 pooled 测量无法证明某部分是纯生物、另一部分是纯噪声。
V22–V29
固定疾病/细胞背景并做跨研究验证。形成 low-rank 基础映射 + program residual 的雏形；小样本结果有方向性，但不足以直接发强结论。
V30–V35
模型家族与选择器成形。V30 大规模内部确认 residual-program，V31 外部 Feng 数据复制；V33 发现不同屏幕的最佳家族会变；V35 第一次真正前瞻测试选择器，联合门槛失败。
V36–V40
从“证明某个模型最好”升级为“可靠地做模型决策”。原代 CD4 T 三状态盲测、guide/供者复现、source 功能 OOD、回退靶点排除与 anchor 数量曲线均已完成并得到一致的正向结果。

注意：版本多不等于独立证据多。真正的独立证据单位是新的研究/屏幕，而不是代码版本、目标基因数量或 bootstrap 次数。

06 · Method

APMA：先判断，再预测

预测 = Σ（某家族在 anchor bootstrap 中成为最佳的概率 × 该家族的预测）
regret = APMA 平均误差 ÷ 同一批盲测目标上的最佳固定家族误差 − 1

外行理解：不是让五位医生永远投票平均。若一位医生证据非常稳定，就听他；若证据摇摆，就按每位医生在重复抽样中“胜出”的频率分配话语权。

07 · Decision rules & results

三状态全部通过，且不是只比弱基线

主门槛：离事后最佳不能太远

每个状态计算 20,000 次目标级 bootstrap；regret 的 95% 区间上界必须 ≤2%。Rest、Stim8hr、Stim48hr 三者全部通过。

为什么不是只看平均改善

如果平均看起来不错、区间却很宽，说明换一批基因可能失败。上界门槛要求“最坏的合理不确定范围”也足够小。

15 · Novelty boundary

可辩护的新意，不该夸大的地方

较有希望的原创组合

  • 把跨背景迁移写成“透明校准家族的决策问题”，而不是单一大模型。
  • 用 anchor OOF bootstrap 的“最佳概率”同时承担不确定性判断与模型平均权重。
  • 明确以 regret 对事后最佳固定家族做门槛，而不仅是对弱基线报改善。
  • 把 guide/供者复现专门用于检验所选 residual 的可复现成分。
  • 从源功能空间选嵌套 anchor，给出目标测量预算曲线。

不能声称原创

  • 低秩映射、基因程序、Ridge、模型平均本身都不是新算法。
  • guide-disjoint、donor-disjoint 复现已被 Huang 等使用。
  • 功能簇 OOD 已由 EL-PERTURB 等强调。
  • control 匹配、split-half 重复性和强基线已是 TxPert/Systema 等的重要规范。
最稳妥的论文定位：一种“面向新细胞背景的、可审计的少样本校准与模型决策框架”，强调什么时候能可靠迁移、什么时候应收缩或拒绝，而不是宣称发明了新的生物学网络。

“最接近”不等于“已经一样”。真正需要在投稿中论证的是：APMA 的决策目标、概率权重和 regret 门槛是否构成非显然、可复现的组合贡献。

18 · Synthesis

文献不是一条排行榜，而是四个互补问题

1. 能不能生成看起来像的细胞？

scGen、CPA、CellOT、GEARS、TxPert 等主要回答预测能力与模型结构。

2. 指标是不是在奖励错误东西？

Systema、Ahlmann-Eltze、Miller 等指出 control 偏差、系统变异与信号稀释。

3. 真正跨背景时机制还一样吗？

Mechanisms Matter、EL-PERTURB 和综合 benchmark 显示跨 context / OOD 会大幅变难。

4. 有多少细节是可重复恢复的？

Huang 的 recoverable resolution 与 intervention geometry 工作强调重复测量、输出分辨率和 same-target anchor。

PerturbCompass 的缝隙：承认不存在一个永远最优的迁移家族，在新背景只付出少量 anchor 成本，用可审计的不确定性决定选谁或平均谁，并把“选择可靠性、重复一致性、OOD、预算”四件事放进同一协议。

22 · Bottom line

结果锁定后的准确总结

PerturbCompass 已从“尝试把目标 control 加进模型”演化为一个更清晰的问题：用少量目标 anchor，可靠地决定跨背景扰动该采用哪一种校准结构，并在证据不足时进行概率平均或收缩。

3 / 3

V36 原代 CD4 T 三状态全部通过 2% regret 联合门槛。

7 / 7

V38 每个状态的全部 source 功能簇中 residual 均胜 low-rank。

32

V40 当前协议下的最小可靠、相对 256 非劣 anchor 预算。

最有价值的论文贡献：不是“又一个模型赢了”，而是一套有失败记录、有数值封印、有重复/供者/OOD/预算验证的可审计答案——在新细胞背景里，测多少、怎么选、何时平均，以及哪些结构改善能跨重复测量保留下来。

本报告已更新为 V36–V40 结果锁定版。最关键的剩余边界是：这些补强分析仍主要嵌套在同一项外部 CD4 T 研究中，下一步应优先争取第二项完全独立的外部验证，而不是继续在本数据上调参。
